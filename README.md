# POS

手機配件行用的收銀與庫存程式。Windows 單機桌面程式，一個 exe 加一個資料庫檔就能用，不需要安裝，也不需要網路。

## 能做什麼

- **收銀**：掃條碼結帳，支援單項折扣、整單折抵、會員折扣，付款方式可自訂。
- **庫存**：進貨、退貨與返修、盤點，每一筆庫存變動都留紀錄。
- **每日立帳**：打烊點錢櫃，系統比對現金銷售算出短溢；立帳後當天的帳鎖定。
- **更正**：結錯的單可作廢重開，付款方式與操作者選錯可更正，都留下紀錄。
- **紀錄查詢**：收銀、進貨、退貨、盤點、立帳、會員，立帳紀錄可複製成月結圖片。
- **商品資料**：依種類設定規格欄位，批次建立款式，列印條碼標籤。
- **會員**：結帳時查詢會員並帶入折扣。

## 身分

- **店員**：收銀、進貨、送出退貨與盤點。
- **管理者**：輸入密碼後可立帳、作廢、更正、核准退貨與盤點、修改設定；一段時間沒操作會自動登出。

## 資料安全

- 資料全部存在程式旁邊的 `pos.db`，不會上傳到任何地方。
- 自動備份到 `backups` 資料夾（保留近幾天、近幾週與近幾個月）；程式升級資料庫前也會先備份。
- 已立帳的銷售、已入帳的庫存紀錄由資料庫本身鎖住，不能事後修改。
